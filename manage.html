作品管理

先到 GitHub Releases 上傳影片，再貼上附件連結，整理你的作品。

更新作品的三個步驟

  1. 到 Releases 上傳影片 ↗，等待完成後複製 MP4 附件連結。
  2. 在下方新增或編輯作品，按「儲存到草稿」。
  3. 按「下載作品資料」，將下載的 portfolio.json 上傳到倉庫根目錄，取代原檔並提交。網站部署完成後會更新。

這個管理頁只在你的瀏覽器整理草稿；公開網站的修改需要由倉庫擁有者登入 GitHub 提交。請勿在網站填入 GitHub 密碼或 Token。
